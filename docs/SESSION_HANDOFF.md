# 세션 인수인계 — KkaiLab World Game Jam

**기준 시각:** 2026-08-15 KST
**현재 단계:** 작업 기반 준비 완료, 이야기 발산 시작 전

## 목표

참가자와 Codex가 만든 짧은 이야기를, Claude가 **현재 로컬 Mac에서** 처음부터 엔딩까지 브라우저에서 플레이되는 단일 HTML 게임으로 구현하고 실제 실행을 검증한다.

## 역할과 권한

| 주체 | 맡는 일 | 맡지 않는 일 |
| --- | --- | --- |
| 참가자 + Codex | 이야기 발산·수렴, 마지막 질문과 엔딩 합의 | 합의되지 않은 이야기의 구현 지시 |
| Claude | 로컬 Mac의 `game/index.html` 구현, 브라우저 실행·플레이 검증 | 세계관·정답·에셋 출처 임의 결정, `qa-pc` 사용, Notion/배포/원격 변경 |
| Notion | 범위, 진행 기록, 결정의 읽기 쉬운 기준점 | 실행 검증의 대체 증거 |

## 작업 순서

1. 참가자가 이야기·조각·이미지·감정을 말한다.
2. Codex는 발산 모드로 듣고, 필요한 때에만 둘 이상의 선택지를 제안한다.
3. 참가자 동의 뒤 마지막 질문·단서·장면을 수렴해 `narrative/STORY_SPEC.md`를 **구현 가능**으로 만든다.
4. Claude가 `game/index.html`의 최소 뼈대를 구현한다.
5. Claude가 실제 브라우저에서 처음부터 두 엔딩과 재시작까지 검증하고 `qa/PLAYTEST.md`에 증거를 남긴다.

## 현재 결정

- 구현물은 워크숍 원본 밖의 `game/`에 둔다.
- `workshop/`은 원본 레퍼런스이므로 수정하지 않는다.
- 구현과 실행 검증은 Claude가 담당한다.
- 구현·검증 호스트는 현재 로컬 Mac 하나이며, `qa-pc`는 이번 프로젝트 범위 밖이다.
- 현재는 이야기가 확정되지 않았으므로 Claude는 게임 기능을 만들지 않는다.

## Claude에 전달할 최소 명세

- 제목
- 시작 장면
- 장소/대화 장면 3~4개와 획득 단서
- 마지막 질문과 답의 형식
- 정답 엔딩·오답 엔딩 텍스트
- 확정된 시각적/음향 요구만

## 검증 완료 기준

- 현재 로컬 Mac에서 `game/index.html`을 더블클릭 또는 로컬 브라우저로 열어 시작한다.
- 필수 단서를 얻은 뒤 마지막 질문으로 갈 수 있다.
- 정답과 오답이 각각 의도한 엔딩으로 간다.
- 재시작이 단서 상태를 초기화한다.
- 확인한 실제 경로와 미확인 항목이 `qa/PLAYTEST.md`에 분리되어 있다.
