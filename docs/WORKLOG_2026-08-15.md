# 작업 로그 — 창문 달 (2026-08-15, 로컬 Mac)

이 문서는 게임잼 프로젝트 "창문 달"의 전체 작업 과정을 시간 순으로 기록한 것이다. 모든 작업은 로컬 Mac에서 수행되었고, qa-pc·Notion·배포는 사용하지 않았다.

## 1. 이야기 발산 (내러티브 대화)

참가자와의 대화로 다음 서사가 확정되었다. 상세 확정본은 `narrative/STORY_SPEC.md`가 기준이다.

- 시간회귀물. 45세·무직·성별 미지정 주인공이 알약 형태의 타임머신 5개를 발견한다.
- 알약 ①: 2008년으로 돌아가 주식(삼성전자·SK하이닉스·엔비디아) 투자 → 부자가 되지만, 친구(어린 시절 동네 친구, 공장을 그만두고 막걸리 양조장 '창문 달'을 연 사람, 주인공의 보증인)는 레버리지·부채·고립·수치의 누적 끝에 세상을 떠난 현재.
- 알약 ②: 레버리지 직전으로 → 미래 고백("나는 이미 한 번, 그 끝을 봤어")은 은폐로 들려 실패. 학습: 미래 정보만으로는 사람을 구할 수 없다.
- 알약 ③: 2008년 동업 제안의 날로 → 제안 수락, 부를 포기 → 친구는 살지만 재개발로 양조장 상실.
- 알약 ④: 재개발 소문 첫날로 → "다른 창문 하나만 같이 보자"로 폐업 목욕탕 이전 성공, 그러나 몰래 선 개인 보증이 휴업·매출 공백과 결합해 주인공만 45세·무직·빚으로 회귀.
- 알약 ⑤: 친구를 처음 만난 어린 날로 → 친구의 대사 **"숨바꼭질 하자."**에서 본편 즉시 종료.
- 핵심 이미지: 창문 달 라벨(회색 공장 벽 창의 흰 달=확대된 쌀알), 목욕탕(파란 타일·높은 창·탕 바닥 달빛·"여긴 물이 아직 길을 알고 있네"), 문장 "이 돈의 첫 보증인은 그 애였다", 문자 "오늘 새 쌀 들어왔어. 시간 되면 와."
- 윤리선: 친구의 죽음은 누적으로만 다루고 방법 묘사·낭만화 금지, 친구를 탐욕/어리석음으로 그리지 않음, 비밀 보증은 영웅적 정답이 아니라 선택을 빼앗은 은폐.

## 2. 수렴과 명세화

- `narrative/STORY_SPEC.md` 작성 → 상태 "구현 가능"으로 확정. 제목 **창문 달** 확정.
- 턴 구조 확정: 알약 발견은 프롤로그(턴 미포함), 본편은 알약 5개 × (과거 개입 1턴 + 바뀐 현재 1턴) = 10턴, 화면에 1/10~10/10 표기.

## 3. 게임 구현의 4단계 (모든 버전이 `game/`에 보존됨)

| 버전 | 파일 | 구조 | 교체 사유 |
|---|---|---|---|
| 선형판 | `index_백업.html` | 낭독형, 턴당 버튼 1개 + 마지막 4지선다 | 상호작용 부족 |
| 상태형 v1 | `index_상태1_백업.html` | 턴당 3선택지 + 상태 패널(관계·양조장·돈·책임) + 조건부 현재 3종 | 선택지 문구가 결과를 노골적으로 암시 |
| 상태형 v2 | `index_상태2_백업.html` | 상황/행동형 문구 + 숨은 기록 8종 + 조합 결정(현재 4~8종) + itch 링크 | 장면을 읽고 다음 버튼으로 가는 단선 |
| **상태형 v3 (현재)** | `index.html` | v2 + 장면 내부 루프 | — |

### v3 (현재 버전) 구조 요약

- **살펴보기 루프(1·3·5·7턴):** 행동 버튼과 별도로 살펴보기 2개씩(보증서 가장자리, 누룩 냄새, 멈춘 손, 발효통, 메모 뒷면, 빈 책상, 재개발 고시, 배수구). 턴 비소비·비잠금, 읽으면 숨은 trace 기록.
- **가져갈 흔적 루프(2·4·6·8턴):** 흔적 카드 3개 중 1개를 골라 세부 장면을 읽어야 다음 알약. 정답/수치 비노출, carry 기록이 이후 장면·문구를 바꿈.
- **기억 지도(9턴):** 정답/오답 질문 폐지. 여러 날의 성찰을 읽고 돌아올 수 있으며(실패·재시도·초기화 없음), '친구를 처음 만난 날'만 10턴 엔딩으로 이어짐.
- **조합 교차 4쌍:** ① confess×t_hand(멈춘 손을 본 고백만 문자가 남음) ② table×ledger×t_edge(서명란 두 줄) ③ solo×c_msg(같은 문장이 두 세월에서) ④ c_label→5턴 선택지 문구 변형.
- **엔딩:** 10/10 "숨바꼭질 하자."에서 즉시 종료. 그 아래에만 itch 링크 — 문구 `꼭꼭 숨어라를 플레이하기`, `https://knuaguy.itch.io/ggogggogsumera`, `target="_blank" rel="noopener noreferrer"`. iframe 금지(itch CSP). URL이 비면 완전 비노출.
- 데이터(GAME)와 엔진 분리 유지. 수정은 상단 데이터 영역에서만.

## 4. 검증 이력 (상세: `qa/PLAYTEST.md`)

모두 로컬 Mac에서, `python3 -m http.server 8642`(127.0.0.1) 경유 Chrome으로 실행. 매 차수 `node --check` 통과·콘솔 오류 0건.

1. **1차** 선형판: 10턴·지식 조각·오답 재시도·재시작 검증.
2. **2차** 상태형 v1: 3경로 완주, 상태 변화·조건부 현재 검증.
3. **3차** 상태형 v2: 5경로 완주, (a)고백의 관계별 분기 (b)공동장부×목욕탕 분기 (c)채무는 휴업 결합 시에만 (d)잔류는 트레이드오프 증명.
4. **4차** itch 링크: 문구·href·target·rel 런타임 확인, 엔딩에서만 노출.
5. **5차** v3: 4경로에서 (a)살펴보기 복귀 (b)흔적 1개 선택 후 진행 (c)교차 3쌍 양방향 실측 (d)기억 지도 무실패 (e)링크 규칙 증명. 단, 이번 세션은 확장의 물리 입력 불능으로 실제 Chrome 탭 내 JS click() 이벤트로 검증(OS 물리 입력 경로는 미실측 — 사람이 직접 1회 클릭 확인 권장).

### 남은 미검증 항목
