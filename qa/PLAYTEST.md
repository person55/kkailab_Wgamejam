### 다섯 플레이의 선택 순서와 결과 (패널: 관계·양조장·돈·책임)

**P1 — 생산표 / 끝을 봤다는 이야기 / 새 계약서 / 조건을 테이블에**
2/10 "생산표는 벽에 붙은 채"(한 배·넉넉히 익는 중·빈손·가벼움) → 4/10 **친구가 멈춰 서서 끝까지 듣고 "반만 하지"** → 6/10 "같은 계약서, 같은 장부 — 이 돈으로는 모자란다" → 8/10 **목욕탕 이전 성공, 빚은 무겁지만 둘 다 아는 숫자**(한 배·넉넉히 익는 중·빈손·무거움). 함께했지만 돈이 모자라는 상충 결과.

**P2 — 보증 정리 / 끝을 봤다는 이야기 / 거리 두기 / 기존 설비 유지**
2/10 "마지막 공동 문서"(끊어질 듯·위태로움) → 4/10 **같은 버튼인데 P1과 달리 경고가 은폐로 들리고 친구는 도장을 찍음** → 6/10 "소문 바깥" → 8/10 **잔류: 통장(빠듯함)과 아침 인사는 보존, 대신 확정 고시 — 문은 열리고 시간이 줄었을 뿐**(끊어질 듯·문 닫기 직전·빠듯함·무거움). 즉시 패배가 아닌 트레이드오프.

**P3 — 시장으로 옮김 / 모자란 금액 메움 / 새 계약서 / 조건은 내가 정리**
2/10 부자·친구 없음·공유 오피스(잃음·사라짐·거부·무거움) → 4/10 "이 세계의 궤도는 굳어 있었다"(혼자 진 빚) → 6/10 **계약서에 이름을 올려 부가 설비·쌀·세월로 녹고 친구가 살아남**(곁에 있음·위태로움·빠듯함) → 8/10 **'조건은 내가' + 이전 뒤 휴업·매출 공백 → 등기 봉투 '보증채무 이행 요청' 발동**(서먹함·작게 익는 중·빈손·혼자 진 빚). 돈이 거부→빈손으로 떨어지는 궤적.

**P4 — 보증 정리 / 끝을 봤다는 이야기 / 라벨만 / 조건을 테이블에**
6/10 "라벨은 당신 것, 장부는 친구 것" → 8/10 **같은 '테이블' 버튼인데 공동장부가 없어 "이 돈으로는 못 옮긴다" — 이전 포기, 공고 아래 잔류**(서먹함·문 닫기 직전·빈손·짓눌림). P1과의 대비로 공동장부 유무가 결과를 가름.

**P5 — 보증 정리 / 모자란 금액 메움 / 라벨만 / 기존 설비 유지**
4/10 "메워진 구멍을 친구는 모른다 — 어디에도 적히지 않은 숫자" → 8/10 **잔류 + 임시메움: 휴업이 없어 채무 미발동. "몰래 메운 숫자는 아직 장부 밖에서 잠들어 있다"**(곁에 있음·위태로움·빠듯함·짓눌림 — 돈 보존, '혼자 진 빚' 아님, 등기 없음).

### 지시된 4개 증명 항목

- **(a) 같은 미래 고백의 분기** — P1(관계 높음: 멈춰 서서 듣고 무리한 계약서를 서랍에 넣음) vs P2(관계 낮음: 은폐로 받아들이고 도장을 찍음). 같은 3턴 버튼, 다른 4턴 본문·패널 확인.
- **(b) 공동장부 유무에 따른 목욕탕 선택 분기** — P1(테이블+공동장부: 공동 감당, 이전 성공) vs P4(테이블만: 비용 앞에서 이전 포기). 같은 7턴 버튼, 다른 8턴 결과 확인.
- **(c) 채무는 휴업과 결합할 때만** — P3('조건은 내가'+이전 휴업: 등기 봉투 발동, 돈=빈손, 책임=혼자 진 빚) vs P5(임시메움+잔류: 휴업 없음 → 채무 미발동, 잠재 부채 서술만). 확인.
- **(d) 잔류는 즉시 패배가 아님** — P2·P5 모두 통장·관계 보존 + 확정 고시(재개발 위험 증가)의 대가 구조. 문은 열려 있다는 서술과 패널 값으로 확인.
